# 저장소 이름 변경 후 배포404 수정

- 문서 버전: v0.0.0
- 생성·수정: 2026-11-03 16:25:57 KST
- 기능 ID: SW_Browser_Logistics_001
- 지시자: 이종인 / 작업자: GPT-6 (Codex)
- 목적: 이용자의 배포화면 접속 실패를 해결하여 시뮬레이션을 사용할 수 있게 한다.
- 목표: 새 저장소 경로에 맞는 자원 로딩을 구현하고 HTML·JS·CSS·모델 응답200을 확인한다.
- 환경: Vite8.3.5, 기존 패키지 유지.

저장소가 SmartFactory_v1.1.0으로 변경됐으나 vite.config.js의base가 이전이름으로 고정돼 있었다. 새HTML은200이지만이전경로로JS·CSS를요청했다. base는배포자원의기준경로다. 이를 './'로변경해빌드산출물이현재폴더의assets를참조하도록했다. README의현재복제·배포주소도새이름으로갱신했다. 과거작업이력URL은보존했다. 사용자README변경은fast-forward로보존했다.

실제설정: export default { base: './' };
Vite빌드→dist/index.html의 ./assets/ 참조→Pages에서현재배포폴더기준해석순서다. npm run build통과,기존청크크기경고유지. 배포성공여부는push후Actions와HTTP로검증한다. 앱운영로직은변경하지않았다.

문제ID: SW_Browser_Logistics_Bug_002. 코드수정완료,원격배포검증예정.
