공정당 AGV 선택 범위를1~3에서1~12로 변경하고 기본값을4로 변경했다. 중간 픽업은 추가하지 않으며 기존 QR 인계 위치를 유지한다. 컨베이어 step·상자생성·QR 코드 변경 없음. 기존 공정 수 선택과 초기화 방식 유지.

MAX_AGVS=12와 agvHome(i)를 simulation.js에서 공유한다. 주차면은 x=7-3*(i%6), z=6+5*floor(i/6)인2줄6칸이며 장면 표지도 같은 함수를 사용한다. 공정 간격29m 안에 들어간다. 주차 출발은 주차면에서 z-2 통로를 지나 픽업으로 이동하고 복귀도 해당 통로를 사용한다. constructor/setAgvCount에서 정수1~12를 검증한다. UI option은12개를 생성하며4가 selected다. FactorySimulation과 Simulation도 기본4대다. 번호10~12는 앞에 불필요한0을 붙이지 않는다.

증차 검증에서 복귀 중 이미 도달한 선대기 합류점을 지나 다시 x13으로 되돌아가려는 교착을 발견했다. pickupRoute는 기존 복귀 경로 중 (10,2.5)까지의 구간을 보존하여 역주행을 방지한다. 이동 중 현재 구간 예약은 유지한다.

검증: npm test21개 통과, npm run build성공, git diff --check통과. 4~12대 각각 seed1/27/998의10분 운행에서 매 프레임 차체 충돌과 상자 보존, 후반 출하 지속 검사 통과. 네 공정 AGV1~12 설정 시 총4*N 및 초기화 확인. 실제12대×4공정 장시간 동시 화면은 미확인. 브라우저 도구가 Work 설정에서 비활성화되어 최종 UI 직접 조작 검증은 불가했다. 기존 내장 브라우저 설정은 변경하지 않았다. JS823.28kB/gzip225.51kB 기존 청크 경고 유지.
