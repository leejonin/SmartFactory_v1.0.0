# 물류 흐름과 병렬 AGV 개념

- 버전: v0.0.7
- 최초 생성·수정: 2026-11-02 (KST)
- 기능 ID: SW_Browser_Logistics_001
- 지시자: 이종인
- 작업자: GPT-6 (Codex)
- 관련 개념: QR 식별, 배차, 공간 점유

목적은 상자가 네 입구에서 세 출하 도크까지 흐르는 과정을 웹 3D 장면으로 보여주는 것이다.

`B`는 활성 상자 집합, `A`는 AGV 집합, `D`는 누적 인도 수, `G`는 생성 수다. `R(a)`는 장비 a가 현재 예약한 다음 직선 구간에 차체 여유를 더한 영역이다. `P(a)`는 현재 차체 점유 영역이다. `intersect`는 겹침, `{}`는 빈 영역이다. `next(a)`는 다음 경유점이다.

```text
G = count(B) + D
count(A) in {1,2,3}  // 현재 UI와 주차 배치의 지원 범위
ReadDest(b) = Decode(QR_pixels(b))
ReadDest(b) = AssignedDest(b) => 인계 가능
ReadDest(b) != AssignedDest(b) => 인계 중지
forall a,c in A, a != c:
  R(a) intersect (R(c) union P(c)) = {} => Move(a,next(a)) 가능
```

개발자 정정: 1대는 필수 조건이 아니다. 여러 대를 사용할 수 있다. 공용 통로 전체 순차 실행은 사용하지 않고, 서로 겹치지 않는 구간에서는 동시에 이동한다. 교차 구간과 단일 인계·도크만 예약한다. 같은 장비에 한 상자만 싣는다.

탑차 3대는 뒤 적재문이 하역대를 향하도록 Y축 180도 회전했다. 컨베이어 끝 X=8과 도크 인도 X=22 사이의 14m는 임시 시뮬레이션 배치다. 실제 설비 규격이나 법정 통로 폭을 의미하지 않는다.

2026-11-02 03:00:26 KST 정정: 상자가 있으면 판독 전에 빈 장비를 QR 옆에 선대기시킨다. 도크 인도 후에도 물량이 있으면 주차보다 QR 직행을 우선한다. 실제 인계는 여전히 QR 성공 이후다. 선배차는 QR 판독 성공을 가정하거나 우회하는 동작이 아니다.


## 4라인 배치 정정 — 2026-11-02 03:24:58 KST

## 2026-11-03 사용자 정정 및 현재 개념

기존 레이어 한 개는 공정 한 개로 부른다. 하나의 공장에 공정 1~4개를 선택하며 기본 작업 모드는 1개다. 이전 공장/레이어 호칭보다 이번 정정이 우선한다.

```text
N in {1,2,3,4}; default(N)=1
Active = first_N(AllProcesses)
Run = Render = Aggregate = Active
AGV_departure_distance >= 2.1 => pickup_owner_release
Move_allowed => reserved_corridors_do_not_overlap
```

인계 자리 해제는 이동 허용의 충분조건이 아니다. 기존 충돌 예약 검사를 함께 통과해야 한다. 현재 개선은 병목의 일부만 줄이며 사용자는 추가 피드백을 예정했다.


## 2026-11-03 AGV 배차·대기 공간 개념 정정

- 작성·수정: 2026-11-03 10:34:10 KST
- 지시자: 이종인
- 작업자: GPT-6 (Codex)
- 기능 ID: SW_Browser_Logistics_001
- 관련 기능 ID: 없음
- 기술 환경: ./Info/기술_환경.md

도크 사용권과 도크 앞 대기 자리 사용권은 별개다. 상자는 QR 성공 후 대기 자리 확보 시 AGV가 먼저 받을 수 있다. 도크가 비면 직행한다. 역할은 차량 번호순으로 고정하지 않고 현재 예상 도착 시간과 선대기 순서에 따른다.

```text
ReserveWaitSlot(d) => PickupAllowed(d)
DockFree(d) => DirectDockRoute(d)
ETA(a) = remaining_travel_seconds + estimated_reservation_delay
Reserved(a,t) = body_and_remaining_segment(a,t) union reserved_exit_turn(a,t)
PassedArea(a,t) not in Reserved(a,t)
```

ETA는 추정이며 4초 정지 비용은 임시 운영값이다. 통과 구간 해제는 차체 여유 폭을 제거한다는 뜻이 아니다.
