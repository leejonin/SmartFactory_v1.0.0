# 공정 컨베이어 상세 화면(키트 실사 재현)

- 상태: 완료(빌드 미확인)
- 버전: v0.0.0
- 지시자: 이종인 / 작업자: Claude Opus 5.5 (Claude)
- 기능 ID: SW_Browser_ConveyorKit_001(신규), 관련 SW_Browser_Logistics_001
- 작성일: 2026-11-03 19:20 KST(작업 시작 시각, 문서는 구현 후 정리)

목적: 공장 화면을 보는 사용자가 한 공정의 컨베이어를 눌러, 실제로 만들 공두이노 DIY 컨베이어 색상 분류 키트와 같은 모습과 동작을 자세히 볼 수 있게 한다.
목표: 공정 컨베이어 클릭 → 별도 페이지(conveyor.html)에서 키트를 실물 크기로 재현하고, 투입→근접센서→컬러센서→서보 게이트→색별 상자 동작을 보여 준다. 실측 부품 모델 파일을 찾을 수 있으면 사용한다.

범위: 새 conveyor.html, src/conveyor/(sorter.js·kit.js·main.js·style.css), Asset/kit-parts/, tests/sorter.test.js, vite.config.js(두 페이지 빌드), src/scene.js·src/main.js(클릭 연결), 버전·문서.
참고 자료: 사용자가 준 키트 사진, 판매 페이지 https://smartstore.naver.com/gongdoriworld/products/9506775109 (작업 환경에서 접속 차단되어 내용 미확인).
부품 모델: FreeCAD-library(CC-BY 3.0) STEP → GLB 변환(occt-import-js).
검증: 분류 로직 자동 테스트, 기존 테스트, 브라우저 장면 스크린샷(전체·센서·게이트·보드), 클릭/드래그 구분 확인.
