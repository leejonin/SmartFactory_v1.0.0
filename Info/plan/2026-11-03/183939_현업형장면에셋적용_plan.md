# 현업형 장면 에셋 적용

- 상태: 완료(빌드 미확인)
- 버전: v0.0.0
- 지시자: 이종인 / 작업자: Claude Opus 5.5 (Claude)
- 기능 ID: SW_Browser_Logistics_001
- 작성일: 2026-11-03 18:39:39 KST

목적: 공장 물류 흐름을 보는 사용자가 3D 화면을 실제 물류센터처럼 느끼도록 하여 시뮬레이션의 현장감과 신뢰를 높인다.
목표: 외부 무료 에셋(GLB)을 장면에 배치하고, 바닥·벽·도크를 실제 물류센터 구성으로 바꾸며, 시뮬레이션 동작·테스트 결과는 그대로 유지한다.

범위: src/scene.js(장면 구성·에셋 로드·상태 문구), Asset/aws-warehouse/(새 에셋), 관련 Info·README 기록. simulation.js·factory.js·main.js의 운영 로직은 변경하지 않는다.

에셋 출처: aws-robotics/aws-robomaker-small-warehouse-world(ros2 브랜치, MIT-0). DAE를 three.js r187 ColladaLoader→GLTFExporter로 GLB 변환.

수행:
1. 격자 바닥 → 콘크리트 텍스처 바닥, 건물 밖 아스팔트 진입로 분리
2. 얇은 벽·기둥·대형 'FLOW / SMART FACTORY' 글자 → 패널 외벽·H형강 기둥·하부 보호대, 시야 쪽 벽은 단면(컷어웨이) 처리
3. 출하 도크 → 도크 벽 개구부·도크 레벨러·범퍼·셸터·볼라드, 탑차를 건물 밖에서 후진 접안한 위치로 이동
4. 유입구 문틀 상자 → 입고 팔레트(박스 적재) + 뒤편 보관 선반, 좌측 고층 파레트 랙
5. 핸드파렛트·작업대·폐기물 수거함 등 현장 소품 배치(AGV·상자 경로 밖)

검증: 기존 자동 테스트, 브라우저 장면 스크린샷 전후 비교, 1~4공정 전환 시 벽·바닥 범위 확인, 콘솔 오류 확인. vite 빌드는 이 작업 환경에서 실행 가능 여부 확인 후 기록.
완료 기준: 위 5개 반영, 테스트 실패 0, 경로와 소품이 겹치지 않음을 화면으로 확인, day/problem 기록.
